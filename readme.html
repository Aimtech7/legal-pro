🚀 Key Core Features

For Legal Professionals

  • Case Lifecycles: End-to-end status tracking with private/public visibility switches.
  • Cloud Documents: Secure uploads of court sheets and evidence directly to Cloudinary.
  • Conflict Resolver: Live appointment calendar widget checking slots to prevent scheduling clashes.
  • Full Audit Trails: Detailed transaction tables recording fees, billing methods, and payouts.

For Clients

  • M-Pesa STK Push: Instant mobile paybills via integrated Safaricom Daraja callback hooks.
  • Real-time Chats: Built-in instant messaging with typing alerts powered by Socket.io.
  • Timeline Updates: Direct view of court dates, files status, and notes.
  • Admittance Portal: Quick self-booking system with auto-email confirmations.

⚙️ Deployment Setup

Local Bootstrap Procedures

Run these simple commands in separate terminals to start the local environments:

1. Setup Local Environment Variables

Copy templates into `.env` at the root and `/backend/.env` inside the backend directory.

2. Boot the API Server

cd backend
npm run start:dev

3. Boot the Web Client

npm run dev
